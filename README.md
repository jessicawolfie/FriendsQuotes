# 📺 Friends Quotes App

An Android application developed in Kotlin that generates iconic quotes from the Friends TV series.

### 🎬 About the Project

This is an Android application created as a development challenge, featuring the most memorable quotes from the Friends series (1994-2004). The app demonstrates navigation between Activities and XML layout manipulation.

### ✨ Features

- **Main Screen**: Friends-themed interface with a button to view a quote
- **Quotes Screen**: Displays a random iconic quote from Friends characters
- **Navigation**: Simple flow between two screens with stylized buttons
- **Thematic Design**: Colors inspired by Central Perk (the coffee shop from the series)


### 🛠️ Technologies Used

- **Language**: Kotlin
- **IDE**: Android Studio
- **Layout**: XML with ConstraintLayout
- **Components**: 
  - Activity
  - Button (with state effects when clicked)
  - TextView
  - CardView
  - Intent for navigation

1. Clone this repository
2. Open the project in Android Studio
3. Wait for Gradle to sync dependencies
4. Run the application on an emulator or physical device

### 📱 App Flow

1. **MainActivity**: 
   - Displays title "Friends Motivational Quotes"
   - Subtitle "☕ Central Perk Wisdom ☕"
   - Button "Click to see today's quote" (changes color when pressed)

2. **SecondActivity**:
   - Randomly selects a Friends quote
   - Displays the quote in a CardView with Central Perk theme
   - Button "Back to Central Perk" to return
